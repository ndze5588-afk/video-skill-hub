第一次用？三步开始

skill 是给 AI 助手的「技能包」。装上之后，AI 就会用对应的工具帮你干活。

  1. 1

    装好 Claude Code

    它是在电脑终端里运行的 AI 助手。按官网的说明安装并登录。

    打开官网 ↗
  2. 2

    挑一个 skill，复制安装命令

    在下面点开想用的 skill，复制安装命令，粘贴到终端按回车就装好了。

  3. 3

    用中文说出你要做什么

    在 Claude Code 里直接说，比如「把这段口播的口误剪掉，再加上字幕」。要用 API key 的 skill，详情里写了要哪家的 key。

用 Cursor、Codex 等其他 AI 工具？点开 skill 详情，里面有对应的安装方式。
